🦠 Detection inputs (KrakenUniq / E-score)

First-pass “is this taxon worth following up?” filter from the Escore table.
- E-score mode (use_evalue_for_detection=false): pass if Escore ≥ escore_threshold and reads ≥ reads_threshold.
- E-value mode (use_evalue_for_detection=true): pass if Guellil_et_al_Evalue meets your cutoff and reads ≥ reads_threshold.
Tip: increase reads_threshold to reduce low-evidence hits.

🦠 ANI, breadth, damage, entropy

Mapping / authenticity evidence thresholds (applied after aligning reads to the pathogen reference).
- ani_threshold: minimum average nucleotide identity (%) across mapped reads.
- breadth_ratio_threshold: minimum breadth ratio (observed breadth / expected breadth). Values closer to 1 indicate coverage is close to expectation.
- damage_5p_ct_threshold, damage_3p_ga_threshold: minimum terminal damage signal. For example, 5' C→T at read ends is used as an ancient-DNA authenticity signal.
- entropy_threshold (bacteria) / entropy_threshold_virus: minimum normalized Shannon entropy of read-start positions along the reference. Higher values mean reads are spread more evenly across the genome.

🦠 HOPS score thresholds

Only used when enable_hops=true. Each threshold is the minimum HOPS score needed to count that criterion as “passed”. Higher values are stricter.

🦠 Edit distance & mapping

Shape-based checks on the edit-distance profile + mapping stability:
- edit_distance_decay_quality_threshold: minimum “decay quality” score for the damaged-reads subset.
- edit_distance_no_damage_decay_quality_min: minimum “decay quality” score for the non‑damaged (no‑damage) subset.
- read_mapping_ratio_threshold: minimum consistency ratio Mapped_reads / Krakenuniq_reads for that pathogen (higher = more consistent).
What is “decay quality”? It summarizes the shape of the edit-distance distribution: reads should generally be more frequent at low edit distance and “decay” as edit distance increases. A higher score means a clearer, better‑behaved decay pattern.
