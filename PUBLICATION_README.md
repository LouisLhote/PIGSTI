# PIGSTI publication kit

This tree is the **release candidate** of PIGSTI (code + docs + portable templates).

## Publish now

Follow the full checklist: **[`docs/RELEASE_AND_ZENODO.md`](docs/RELEASE_AND_ZENODO.md)**

Quick path:

1. Confirm local path files are ignored (`config/config.yaml`, `samples.tsv`, `Pathogen_spreadsheet.csv`).
2. Push to GitHub → create annotated tag `v1.0.0` → GitHub Release.
3. Link the repo in Zenodo (GitHub integration) so the release gets a DOI.
4. Paste the DOI into `CITATION.cff`, `.zenodo.json`, and the README badge/BibTeX.
